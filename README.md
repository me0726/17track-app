# 物流查询

Electron + React + Tailwind CSS + shadcn 应用，包含物流查询、任务记录和原始内容三个页面。主窗口初始为 800 × 600，支持调整大小，最小为 800 × 600，顶部切换页面，底部显示当前查询状态。

导入 Excel 或粘贴快递单号，点击“开始查询”；应用在 17TRACK 中按 40 个分批查询，等待加载结束，点击操作栏的第二个按钮，在页面内拦截 `execCommand("copy")` 并显示结果。自动提取不会修改系统剪贴板。出现人机验证时在浏览器中手动完成。

任务和单号结果保存在 SQLite 的 `task`、`task_item` 中。任务详情仅显示单号、物流信息、状态，按状态分页，支持等待中、处理中、已完成、失败筛选；可导出整个任务的 Excel 明细。任务只有查询中、暂停、已结束三种状态。暂停任务可继续等待中的单号；已结束任务可在详情中重试失败项，先回退为等待中再重新查询。数据库路径为 Electron 用户数据目录下的 `trackbox.sqlite`。

17TRACK 复制结果按制表符解析为：快递单号、始发地、目的地、最新轨迹、物流状态、运输时长。缺少单号或格式错误的明细会标记为失败。

每批完整复制文本单独保存在 `task_batch`，保留制表符、换行和未解析内容。在任务详情点击物流信息即可打开对应原始批次；重试会新增批次，保留旧原文。原始内容页可按完整单号精确搜索，列出该单号在不同任务及重试中出现的全部批次，包含解析失败或未返回该单号结果的批次。当前处于开发阶段，直接按当前表结构创建数据库，不包含旧结构的数据迁移。

```bash
npm install
npm run dev
```

调试：`OPEN_DEVTOOLS=1 npm run dev`。构建：`npm run build`。测试：`npm test`。

详细流程见 [功能与代码结构](docs/architecture.md)。
